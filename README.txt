TONY BUDGET - PRIVACYVERSIE

De publieke bestanden bevatten geen persoonlijke bedragen.
Bij eerste start stel je lokaal een pincode in en vul je je eigen cijfers in.
Pincode-hash en budgetdata worden uitsluitend in de browser/localStorage op je toestel bewaard.
De pincode is lokale appvergrendeling, geen server-authenticatie.
Gebruik regelmatig Exporteer in de app om een back-up te bewaren.

Voor GitHub Pages upload je index.html, manifest.webmanifest en sw.js samen in één repository.
